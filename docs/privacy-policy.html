Smart Locator Inspector – Privacy Policy

Last updated: October 9, 2026

Smart Locator Inspector is a Chrome extension that helps testers generate locators (Playwright and Selenium) for elements on a web page. It is designed to work entirely inside your browser.

Data we collect

None. The extension does not collect, store, sell or transmit any personal information, browsing history, page content or form data. There is no account, no analytics, no telemetry and no server.

How page content is used

Only after you click the extension icon (or use its keyboard shortcut) and start inspection, the extension reads the structure of the current tab (tag names, attributes, labels and short visible text) to build locator suggestions. This processing happens locally in memory in that tab. Results are shown only in the extension's own popup and on-page panel and are discarded when the page is closed or reloaded.

The extension never reads values typed into text fields, never reads password values, and does not send any page data anywhere.

Permissions

  • activeTab – temporary access to the current tab, granted only when you click the extension icon or use its shortcut.
  • scripting – to inject the inspector into that tab on demand.

The extension does not request access to all websites and does not run automatically on any page.

Storage

The only thing stored is your preferred framework tab (Playwright or Selenium) in the extension's local storage. No page content is stored.

Third parties

No data is shared with third parties. The extension loads no remote code.
